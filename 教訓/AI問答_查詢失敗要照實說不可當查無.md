# AI問答:資料庫查詢出錯要說「查詢失敗」,不可當 0 筆
- 發生什麼:以前查詢出錯被當 0 筆,AI 回「沒有相關紀錄」(從最初版本如此)。
- 做法(11/03):任何查詢出錯記到 `queryErrors`,整題回「查詢失敗,請稍後再試(不代表沒有相關紀錄)」,`query_failed:true`,不呼叫 AI、不寫問答歷史。新增查詢也要沿用這寫法。
- 時間詞 `parseTimeRange`:看不懂的(下個月、昨天)答案開頭明講「未能辨識,以下為全部期間」;時間詞不當搜尋詞;CRM 不依時間篩;「最近」單獨不篩日期。
- 逾時教訓(11/04):「本月TM」回答太長連 3 次逾時 → 單次逾時 48 秒、只重試 1 次、總時限 55 秒(vercel.json 60)、max_tokens 2000、提示詞要求簡短摘要。
